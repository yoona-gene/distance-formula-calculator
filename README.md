# Distance Formula Calculator

## Description
This program calculates the distance between two points using input values (x and y) a math library (math.sqrt and math.pow).

## How to run
1. Open the program file.
2. Run the program.
3. Enter the value of x1.
4. Enter the value of y1.
5. Enter the value of x2.
6. Enter the value of y2.
7. Check the distance calculated.

## Inputs needed
1. x1
2. y1
3. x2
4. y2

## Sample output
Enter x1: 2
Enter y1: 3
Enter x2: 5
Enter y2: 7

Distance : 5.0
